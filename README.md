# News Promo — новостной промо-сайт

## Технологии
- Java 17+
- Spring Boot 3.3
- Spring Security
- Spring Data JPA
- Thymeleaf
- PostgreSQL


## Возможности

- Лента постов, страница поста, лайки и комментарии.
- Регистрация и вход в модальных окнах.
- Роли `USER` и `ADMIN`. Админка `/admin`: публикация, скрытие и удаление постов, модерация комментариев (одобрить, скрыть, удалить).
- Пользователь с ролью `ADMIN` может выдавать наказания `Ban` или `Mute`, путем поиска нужного пользователя чере раздел `Пользователи`

## Запуск

```bash
docker compose up -d       
mvn spring-boot:run        # http://localhost:8080
```

При первом старте создаётся админ `admin` / `admin12345`.
Подключение к БД настраивается переменными `DB_URL`, `DB_USER`, `DB_PASSWORD`.

Таблицы создаёт Hibernate (`ddl-auto: update`).

## Безопасность

- Пароли хранятся в BCrypt.
- CSRF включён: Thymeleaf добавляет токен в формы, запрос лайка берёт его из `<meta>`.
- `/admin/**` закрыт правилом `hasRole('ADMIN')` и `@PreAuthorize` на контроллере.
- Пользовательский текст выводится через `th:text`, HTML не исполняется.
